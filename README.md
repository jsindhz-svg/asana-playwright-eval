# Asana Playwright Test Evaluation

Data-driven end-to-end test suite for the Asana-like demo application using Playwright and TypeScript.

The suite validates six task scenarios across Web Application and Mobile Application projects, including task names, columns, and tags.

## Tech Stack

- Playwright
- TypeScript
- Node.js
- JSON-based test data
